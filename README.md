JunctionStore Database Project



Overview
JunctionStore Database Project is a comprehensive relational database solution developed for a retail store environment. The project demonstrates database design principles, data modelling, table relationships, and SQL implementation using MySQL.

The system is designed to ensure efficient data storage, maintain data integrity, and support daily business operations through well-structured tables, primary and foreign key relationships, and SQL queries.

Technologies Used
MySQL
SQL (DDL & DML)
MySQL Workbench
Relational Database Design
Features
Product management
Customer record management
Supplier management
Sales transaction tracking
Inventory management
Relational table structure with primary and foreign keys
Data querying and reporting
Database normalisation and integrity constraints
Purpose
The purpose of this project is to demonstrate the ability to design, build, and manage a complete retail database system while applying industry-standard database development practices.
